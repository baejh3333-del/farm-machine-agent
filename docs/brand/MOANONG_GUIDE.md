# 모아농 디자인·문체 가이드 (바이브 코딩용) v1.1

> **사용법**
> - 화면을 AI로 만들 때(Claude, Cursor, v0 등) **이 파일 전체를 프롬프트 맨 앞에 붙여 넣거나**, 프로젝트 폴더에 넣고 "MOANONG_GUIDE.md를 따라 만들어 줘"라고 말해요.
> - 색·글자 크기는 `moanong-tokens.css`의 변수만 써요. 로고는 `logo/` 폴더의 SVG 파일을 그대로 써요.
> - 이 가이드와 다른 결정을 했다면 혼자 바꾸지 말고 팀에 먼저 공유해요.

---

## 0. AI에게 주는 규칙 (꼭 지킬 것)

1. 이 문서의 **색, 글꼴, 모양, 문체 규칙**을 그대로 따른다. 새 색·새 글꼴·그라데이션·이모지를 만들지 않는다.
2. 모든 색과 크기는 `moanong-tokens.css`의 `--mn-*` 변수로 쓴다. 16진수 색을 직접 쓰지 않는다.
3. 글꼴은 **Pretendard 하나만** 쓴다.
4. **초록(`--mn-green`) 버튼은 한 화면에 하나**만 둔다. 나머지 버튼은 테두리 버튼(`.mn-btn-outline`)이나 검정 버튼(`.mn-btn-dark`)으로 둔다.
5. 초록은 화면의 약 8%만 쓴다. 넓은 배경을 밝은 초록으로 칠하지 않는다.
6. 모든 문구는 **해요체**로 짧고 쉽게 쓴다. (아래 6장 참고)
7. 로고 SVG의 모양·비율·색을 바꾸지 않는다. 글자로 "모아농"을 써서 로고를 대신하지 않는다.
8. 내용이 정해지지 않은 자리는 지어내지 말고 `[대여료]`, `[질문 1]`처럼 **대괄호**로 비워 둔다.

## 1. 브랜드 한 줄

**이웃의 쉬는 농기계를, 클릭 한 번으로.**
‘모아’와 ‘농’을 합친 이름처럼, 동네 농기계를 한곳에 모아 필요한 사람과 이어 주는 농기계 대여·중고 거래 서비스예요. AI 도우미의 이름은 **농농이**예요.

- 핵심 가치 3가지: **간결함**(클릭 한 번) · **농기계 대여** · **이웃 연결**
- 주요 사용자: 처음 농사를 시작하는 사람(빌리는 분), 쉬는 농기계가 있는 농가(빌려주는 분), **시니어**
- 분위기: 깔끔한 흰색·회색 바탕, 초록은 포인트로만. 친근하지만 유치하지 않게.

## 2. 로고

| 파일 | 쓰는 곳 |
|---|---|
| `logo/moanong-logo.svg` | 기본 (흰·밝은 바탕) — 헤더 높이 36px |
| `logo/moanong-logo-white.svg` | 포레스트·검정 바탕 — 푸터 높이 32px |
| `logo/moanong-symbol.svg` / `-white` | 앱 아이콘, 농농이 프로필, 작은 마크 |
| `logo/moanong-wordmark.svg` / `-white` | 심볼 없이 글자만 필요할 때 (드묾) |

- **심볼**: 트랙터 옆모습. 초록 몸체 = 밭과 작물, 둥근 돌기 바퀴 = 실제로 굴러가는 농기계·함께 움직이는 이웃.
- **워드마크**: ‘아’ 위 새싹 = 초보 농사꾼도 함께 자람. 굵고 둥근 획 = 시니어도 읽기 쉬움.
- 여백: 로고 둘레에 ‘아’의 ㅇ 높이만큼 비워 둠.
- 최소 크기: 전체 로고 높이 24px, 심볼만 20px.
- 금지: 늘이기·눕히기, 색 바꾸기, 그림자·테두리 넣기, 바퀴 모양 바꾸기.

|---|---|---|---|
| 메인 그린 | `--mn-green` | #1E9B4B | 메인 버튼 1개, 선택한 날짜, 완료 단계 원 |
| 딥 그린 | `--mn-green-text` | #13773A | 초록 글자, 섹션 라벨, 배지 글자, 초록 아이콘 선 |
| 포레스트 | `--mn-forest` | #0F3B24 | 넓은 브랜드 면 — **페이지당 한 번** (마지막 CTA 섹션) |

| 그레이 | `--mn-gray` | #555555 | 보조 글자 |
| 라이트 그레이 | `--mn-gray-light` | #767676 | 캡션, 힌트 (이보다 연한 글자 금지) |
| 라인 | `--mn-line` | #EEEEEE | 구분선 |
| 바탕 | `--mn-bg` | #F6F6F6 | 섹션 배경, 입력 칸이 놓이는 패널 |
| 오류 | `--mn-danger` | #D93025 | 오류 문구에만 |

**비율**: 흰색·회색 70% / 잉크 22% / 그린 8%.

**초록을 쓰는 곳은 세 가지뿐**
1. 누르는 곳 — 그 화면의 가장 중요한 버튼 1개
2. 고른 것 — 선택한 날짜, 선택된 항목
3. 좋은 소식 — ‘대여 가능’, ‘승인 완료’ 배지, 체크 표시, 새싹

**쓰지 않는 곳**: 헤더·메뉴, 가격, 본문 글자, 여러 섹션의 배경, 보조 버튼.

## 5. 모양과 컴포넌트

- 모서리: 버튼·입력 12px / 사진·작은 카드 16px / 팝업 20px / 큰 카드 24px / 칩·배지·토글 999px(완전 둥글게)
- 높이: 메인 버튼 52px, 입력 칸 50px. **누르는 곳은 최소 48px.**
- 그림자: 카드 `--mn-shadow-card`, 팝업 `--mn-shadow-pop`. 그 외 그림자 금지.
- 레이아웃: 본문 최대 폭 1200px, 좌우 24px, 섹션 위아래 120px.
- 사진: 실제 농기계 사진, 모서리 16px, 비율 4:3.4. 일러스트·3D 아이콘은 쓰지 않아요.
- 아이콘: 선 굵기 1.6~2px의 단순한 선 아이콘. 색은 잉크, 포인트일 때만 딥 그린.

| 컴포넌트 | 클래스 | 규칙 |
|---|---|---|
| 메인 버튼 | `.mn-btn-primary` | 초록, 한 화면에 하나. 예: ‘농기계 찾기’, ‘대여 요청 보내기’ |
| 확인 버튼 | `.mn-btn-dark` | 팝업 안 ‘적용’, ‘확인’ |
| 보조 버튼 | `.mn-btn-outline` | 흰 바탕 + #DDD 테두리. 예: ‘로그인’, ‘전체 보기’ |
| 입력·선택 칸 | `.mn-field` | 회색 패널 위의 흰 칸, 열리면 검정 2px 테두리 |
| 팝업 | `.mn-popup` | 칸 바로 아래 말풍선처럼 열림(위쪽 작은 삼각형) |
| 배지 | `.mn-badge` / `--muted` | 좋은 상태는 새싹 틴트, 나머지는 회색 |
| 섹션 라벨 | `.mn-label` | 제목 위의 작은 딥 그린 글자. 예: ‘주요 기능 01’ |
| 아이콘 원 | `.mn-icon-circle` | 새싹 틴트 원 + 딥 그린 선 아이콘 |
| 달력 | `.mn-day--selected` / `--in-range` | 시작·끝은 초록 원, 사이는 새싹 틴트, 지난 날은 연회색 |
| 대여/중고 토글 | — | 회색 트랙 + 흰 동그라미가 미끄러짐, 글자는 검정 |
| 마지막 CTA 섹션 | `.mn-section-forest` | 포레스트 바탕, 흰 버튼(글자 포레스트) + 흰 테두리 버튼 |

## 6. 문체 (글을 쓰는 법)

### 기본 목소리
**옆집 농가 선배가 쉽게 알려 주는 말투.** 친절하지만 길지 않고, 전문 용어 대신 하는 일로 말해요.

### 규칙
1. **해요체**로 끝내요. (‘~합니다’, ‘~하세요!’, 반말 금지)
   - ✅ 가까운 매물을 바로 보여드려요. ❌ 가까운 매물을 제공합니다.
2. **한 문장은 짧게**, 한 줄에 한 가지 생각만. 두 줄이 넘으면 나눠요.
3. **기계 이름보다 하는 일**로 말해요. 전문 용어는 괄호로 풀어요.
   - ✅ 밭 갈기 (경운·로터리) ✅ 방제 (약 뿌리기)
4. **영어·외래어는 피해요.** 매칭 → 연결, 리스트 → 목록, 체크 → 확인, 렌탈 → 대여.
5. **느낌표·이모지·물결(~)을 쓰지 않아요.**
6. ‘간편하게’, ‘쉽게’를 남발하지 않고, 대신 **몇 번이면 끝나는지** 말해요.
   - ✅ 네 번이면 충분해요. ✅ 날짜만 고르면 끝.
7. 사용자를 부를 때는 **‘빌리는 분’, ‘빌려주는 분’**이라고 해요. (고객님, 회원님 X)
8. AI는 항상 **‘농농이’**라고 불러요. (챗봇, AI봇 X) 농농이도 해요체로 말해요.

### 문장 다듬기 규칙 (v1.1, 토스 UX 라이팅 참고)
| 규칙 | 말고 | 이렇게 |
|---|---|---|
| 능동형 | 요청이 승인되었어요 | 김농부님이 요청을 승인했어요 |
| 긍정형 | 로그인하지 않으면 요청할 수 없어요 | 로그인하면 바로 요청할 수 있어요 |
| 가벼운 높임 (‘~시’, ‘~께’ 빼기) | 대여하시겠어요? | 대여할까요? |
| 명사+명사 풀기 | 반납 일정 변경 신청 | 반납 날짜 바꾸기 |
| 팝업 왼쪽 버튼 | 취소 | 닫기 |

### 쓰고 나서 묻는 8가지
1. 버튼만 보고 다음 화면을 알 수 있나요? (시작하기 → 위치 고르기)
2. 빠져도 뜻이 같은 단어를 지웠나요?
3. 제목과 같은 말을 반복하는 문장을 지웠나요?
4. 지금 필요 없는 설명을 뺐나요?
5. 소리 내 읽어도 자연스럽나요? (경운 작업 시 → 밭을 갈 때)
6. 겁주거나 강요하지 않았나요? (지금 안 빌리면 마감돼요 → 이날 빌릴 수 있는 기계가 2대 있어요)
7. 유행어·영어 없이 모두가 알아듣나요?
8. 정보 뒤의 마음을 살폈나요? (반납이 완료되었습니다 → 올해 농사도 수고 많으셨어요)

### 화면 원칙
- 하지 않아요: 들어오자마자 팝업, 뒤로 가기를 막는 팝업, 나갈 길(닫기) 없는 화면, 갑자기 나오는 광고, 설명만 반복하는 버튼
- 그래픽: 핵심 그래픽은 하나만, 파티클·과한 그라데이션 금지, 오류가 아니면 느낌표 아이콘 금지, 아이콘은 24~40px로 하나씩

### 버튼 문구
- **[무엇] + [하기/동사]**, 2~6글자. 마침표 없음.
- ✅ 농기계 찾기 · 대여 요청 보내기 · 농기계 등록하기 · 적용 · 초기화 · 전체 보기 →
- ❌ 확인하러 가기 · 클릭하세요 · 지금 바로 시작하기!
- 다음 화면으로 넘어가는 링크만 끝에 ‘→’를 붙여요.

### 제목 문구
- 쉼표로 두 박자를 만들어요: **[상황], [해결]**
- 예: 농기계, 클릭 한 번으로. / 처음이어도, 순서대로 작업 가이드 / 전화 없이, 간편한 대여 요청

### 안내·오류 문구
- 무슨 일이 있었는지 → 어떻게 하면 되는지 순서로. 사용자를 탓하지 않아요.
- ✅ 하루만 빌릴 때는 반납 시간이 받는 시간보다 늦어야 해요.
- ✅ 아직 맞는 농기계가 없어요. 범위를 넓혀 볼까요?
- ❌ 잘못된 입력입니다. ❌ 오류가 발생했습니다!

### 빈 화면
- 사과하지 말고 다음 행동을 알려요. ✅ 아직 빌린 농기계가 없어요. 필요한 작업으로 찾아보세요.

## 7. 접근성 (시니어 배려) 체크리스트

- [ ] 본문 15px 이상, 대비 4.5:1 이상 (초록 글자는 #13773A)
- [ ] 누르는 곳 48px 이상, 버튼 사이 8px 이상 간격
- [ ] 색만으로 상태를 알리지 않기 (선택 = 색 + 굵기, 오류 = 색 + 문구)
- [ ] 아이콘만 있는 버튼에는 `aria-label`
- [ ] 한 화면에 고를 것은 적게, 기본값은 미리 채워 두기
- [ ] 마우스 휠·직접 입력 둘 다 되게 (시간 선택처럼)

## 8. AI에게 화면을 부탁할 때 쓰는 프롬프트 예시

```
MOANONG_GUIDE.md와 moanong-tokens.css를 따라서 [화면 이름]을 만들어 줘.
- 목적: [이 화면에서 사용자가 해야 할 일 한 가지]
- 메인 버튼(초록, 1개): [버튼 문구]
- 들어갈 내용: [항목들]
- 정해지지 않은 내용은 [대괄호]로 비워 둬.
- 문구는 해요체로, 가이드 6장의 문체를 지켜 줘.
- 만든 뒤 가이드 7장 체크리스트를 스스로 확인하고 어긴 곳을 알려 줘.
```
